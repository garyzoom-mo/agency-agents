# 阶段 5：通达信公式侧接入

> 目标：在通达信里**肉眼看到**Python 的信号，并且逐日对齐、能选股、能预警。
> 这一步的验收标准是"你亲眼看到了"，不是"脚本说写好了"。

## 输入 / 输出

- **输入**：阶段 4 的落盘文件 + 数据号清单
- **输出**：① 可用的指标/选股/预警公式（文本，入库）② 逐日对齐验收记录 ③ 通达信操作步骤说明

## 1. 函数速查（Python 数据 → 公式取值）

| 你的数据 | 公式函数 | 说明 |
|---|---|---|
| 自定义序列数据（日期+数值） | `SIGNALS_USER(数据号, 0)` | 第二个参数 `0`=自定义数据，`1`=系统数据。按当前 K 线日期取值 |
| 外部数据 · 字符串 | `EXTERNSTR(0, 数据号)` | 第一个参数 `0`=自定义外部数据，`1`=系统数据 |
| 外部数据 · 数值 | `EXTERNVALUE(0, 数据号)` | 与上同源，取数值 |
| 自定义板块 | 板块名直接可用 | 选股器/盯盘里直接选板块，无需公式 |

**静默失败警告**：数据号不存在时，这些函数**返回 0 而不是报错**。所以看到一片 0 时，
第一个要查的就是数据号是否建好、是否写在了同一个通达信目录。

## 2. 公式模板（复制即用）

### 2.1 副图：把信号画成状态线

```
{名称：TQ信号_副图   类型：技术指标}
SIG: SIGNALS_USER(100,0), COLORRED, LINETHICK2;
```

更直观的版本（持有时在上方画柱、空仓时在下方画柱）：

```
SIG:=SIGNALS_USER(100,0);
STICKLINE(SIG=1, 0, 1, 3, 0), COLORRED;
STICKLINE(SIG<1, 0, -1, 3, 0), COLORGRAY;
```

### 2.2 主图：在翻转处标箭头 + 显示状态文字

```
{名称：TQ信号_主图   类型：主图叠加}
SIG:=SIGNALS_USER(100,0);
READY:=BARSCOUNT(CLOSE)>5;                        {前几根K线REF无效，先挡掉}

DRAWICON(READY AND SIG=1 AND REF(SIG,1)<1, LOW*0.98, 1);        {开多}
DRAWICON(READY AND SIG<1 AND REF(SIG,1)=1, HIGH*1.02, 2);       {平仓}
DRAWTEXT_FIX(1, 0.01, 0.05, 0, STRCAT('信号：', EXTERNSTR(0,101))), COLOR00FFFF;
DRAWTEXT_FIX(1, 0.01, 0.09, 0, STRCAT('仓位：', CON2STR(EXTERNVALUE(0,101),0))), COLOR00FF00;
```

> `DRAWTEXT_FIX(1, x, y, 0, 文字)` 的前两个数字是相对坐标，按你的界面宽度微调。
> 公式里想显示中文，注意用 `STRCAT` 拼接而不是直接写字面量后跟变量。

### 2.3 条件选股公式（选"今天新出信号"的票）

```
{名称：TQ选股_新开仓   类型：条件选股}
SIG:=SIGNALS_USER(100,0);
XG: SIG=1 AND REF(SIG,1)<1;
```

**硬性限制**：条件选股公式里**不能使用绘图函数**（`DRAWICON/DRAWTEXT/DRAWNUMBER` 等），
写了会保存失败或选不出票。要看图就把绘图部分单独做成指标公式。

其他常用选股条件：

```
{持续持有中}
SIG:=SIGNALS_USER(100,0);
XG: SIG=1;

{连续3天持有（更稳的过滤）}
SIG:=SIGNALS_USER(100,0);
XG: SIG=1 AND REF(SIG,1)=1 AND REF(SIG,2)=1;

{刚平仓（复盘用，别拿来下单）}
SIG:=SIGNALS_USER(100,0);
XG: SIG<1 AND REF(SIG,1)=1;
```

### 2.4 预警设置

通达信 → `预警`（或 `功能 → 预警设置`）→ `条件预警`：
1. 公式选 `TQ选股_新开仓`，周期选日线（或你的信号频率对应周期）。
2. 预警方式勾选"弹出提示 / 声音 / 写入板块"，建议同时勾"加入板块"便于开盘直接看。
3. **必须理解**：预警只在信号文件**已经更新**之后才会触发。也就是说，若你用收盘后写入的制度，
   预警最早在次日开盘后触发一次 —— 想做"当日盘中预警"，信号必须盘中写入（阶段 4 的 live 模式）。

### 2.5 板块的用法（最贴合通达信体验的通道）

Python 写好 `.blk` 后，在通达信里：
- 直接打开该自定义板块看行情、做复盘；
- `选股器 → 综合选股 → 自定义板块` 里当股票池，与其他条件组合；
- 配合"板块指数"功能看整体表现。

## 3. 语义陷阱（每年都有人在这里踩坑）

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 停牌/无 K 线日取不到值 | `SIGNALS_USER` 按 K 线日期对齐，没有那天的 K 线就没有那天数据 | Python 侧**逐日写满**；选股时用 `SIG=1 AND REF(SIG,1)<1` 而不是依赖稀疏事件 |
| 数据号不存在 → 静默返回 0 | 公式不会报错，只会全 0 | 上线前用"已知 3 天数据"做画图验证（阶段 4 第 5 节） |
| 未来函数 | `ZIG / BACKSET / REFX / 部分 DRAWLINE 用法` 会用未来数据 | 实盘预警与选股里**禁止使用**；只在事后复盘图里用 |
| 复权口径错位 | Python 用前复权算价格类信号，通达信画不复权 K 线 → 位置对不上 | 状态类信号（0/1）不受影响；价格类信号务必注明口径并统一 |
| 缓存未刷新 | 写完文件通达信仍显示旧值 | 切周期/重进视图；必要时重启（把结论写进运维手册） |
| 跨品种截面排序 | 通达信公式是逐 K 线求值，做不了真正的截面排序 | 截面类逻辑在 Python 侧算完，只把结果桥过去 |
| 公式写得过重 | 里循环+多函数嵌套会让软件卡 | 复杂计算留在 Python；公式只做"取值 + 简单条件 + 绘图" |
| 混用系统数据 | `EXTERNSTR(1, ID)` 是系统数据，与自定义数据编号体系不同 | 明确 `0`/`1` 参数含义，别抄错 |

## 4. 逐日对齐验收（阶段 5 的正式验收动作）

```
1. Python 侧导出信号，同时打印/保存"日期 → 信号值"的对照表（CSV）。
2. 通达信里打开该票，公式副图显示 SIG。
3. 抽查 10 个日期（含至少 2 个信号翻转日、1 个停牌日附近），逐个核对数值一致。
4. 把抽查结果与截图贴进验收记录；不一致就先别进阶段 6。
```

自动化辅助：`python example_strategy.py verify --tdx-dir "C:/new_tdx"` 会读回文件并报告
"条数 / 最新日期 / 距今几天"，能挡住"文件在但数据是旧的"这类问题（但**不能**替代人工肉眼核对）。

## 5. DLL 进阶（只在必要时才上）

**什么时候值得**：手工刷新/重进视图已经明显影响交易效率，或需要秒级更新。
**什么时候不值得**：日频收盘信号 —— 文件桥足够，DLL 纯属自找麻烦。

要点：
1. 绑定流程：`公式管理器 → DLL函数 → 打开绑定 → 选择 T0002\dlls\xxx.dll`，绑定为第 n 号；
   公式里用 `TDXDLLn(funcid, p1, p2, p3)` 调用（n = 1~10，对应第几号 DLL 绑定）。
2. 官方规范要求导出注册函数（形如 `RegisterTdxFunc(PluginTCalcFuncInfo** pFun)`），
   计算函数签名形如 `void func(int DataLen, float* pfOUT, float* pfINa, float* pfINb, float* pfINc)`。
   **以你安装目录下官方《通达信 DLL 函数编程规范》为准**，不同版本接口有差异。
3. Python 侧的角色：用 `cffi` / `ctypes` 生成 C 扩展（需要编译器，如 MSVC Build Tools 或 `zig cc`），
   DLL 内部读取 Python 落盘的信号文件并返回给公式 —— 这样既保留 Python 计算，又免去手工导入。
4. **安全红线**：DLL 在通达信进程内运行，任何崩溃都会拖垮整个软件。
   必须在 DLL 内做异常兜底、超时保护、以及"读不到数据就返回上一个有效值/0"的降级策略。
5. 上 DLL 前先做压力验证：连续运行一整个交易日、切换周期 100 次无崩溃，才允许实盘使用。
