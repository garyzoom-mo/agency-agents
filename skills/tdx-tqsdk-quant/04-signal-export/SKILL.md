# 阶段 4：信号落盘桥（Python → 通达信）

> 目标：让"Python 算出来的信号"变成"通达信读得懂的文件"，并且**可重复、可校验、失败可见**。

## 输入 / 输出

- **输入**：阶段 3 通过验证的信号序列 + 阶段 1 的数据号约定
- **输出**：① 落盘脚本（或直接复用 `reference/tdx_bridge.py`）② 写后读回校验输出 ③ 文件格式本机验证记录

## 1. 三条通道（先选通道，再写代码）

| 通道 | 落地文件 | 记录格式 | 通达信公式读取 | 最适合 |
|---|---|---|---|---|
| **A. 外部数据**（字符串+数值，每票一条） | `<TDX>\T0002\signals\extern_user.txt` | 每行 `市场\|代码\|数据号\|文字串\|数值`（GBK，CRLF） | `EXTERNSTR(0,数据号)` / `EXTERNVALUE(0,数据号)` | 最新状态、动作、评级、备注（人要看的文字） |
| **B. 自定义序列数据**（日期+数值，时间序列） | `<TDX>\T0002\signals\signals_user_<数据号>\<市场>_<代码>.dat` | 小端 `int32` 日期(YYYYMMDD) + 小端 `float32` 数值，逐条连续存放 | `SIGNALS_USER(数据号, 0)` | 每日仓位/评分序列（图上画、选股用） |
| **B'. 官方导入 txt**（同 B 的数据） | 任意路径 `.txt` | 每行 `市场\|代码\|YYYYMMDD\|数值` | 同上 | 最稳妥、可审计；在「自定义数据管理器」手工导入 |
| **C. 自定义板块** | `<TDX>\T0002\blocknew\<板块名>.blk` | 每行 7 字节：`市场(0深/1沪)` + 6 位代码 + CRLF | 板块本身（可直接选股/盯盘） | 今日选出的股票清单、股票池 |
| D. DLL 自绘（进阶） | `<TDX>\T0002\dlls\xxx.dll`，公式管理器绑定为第 n 号 | `TDXDLLn(funcid, p1, p2, p3)` | 任意 | 免手工刷新、秒级；成本最高（要 C 编译器） |

**市场号**：`0`=深圳、`1`=上海、`2`=北京（自定义数据的社区口径；`.blk` 常见口径只写 0/1，
北交所请按下面的"本机验证清单"实测后再依赖）。

**选通道的默认答案**：要"今天买哪些"→ 通道 C；要在图上看到信号序列 → 通道 B/B'；
要显示一句话状态 → 通道 A。**能用简单通道就别上 DLL**。

## 2. 用现成实现（推荐）

```python
from tdx_bridge import TdxBridge, split_symbol

bridge = TdxBridge(r"C:\new_tdx", series_id=100)

# 通道 B：每日目标仓位（逐日写满，包括空仓日 0）
bridge.write_user_series("SSE.600519", {20240902: 1.0, 20240903: 1.0, 20240904: 0.0})

# 通道 A：一句话状态（merge=True 默认保留文件里其它数据号的内容，不覆盖别人的数据）
bridge.write_extern_user([("SSE.600519", "09-04 平仓", 0.0, 101)])

# 通道 C：今日选股池
bridge.write_block("TQ_SIGNAL", ["SSE.600519", "SZE.300750"])

# 通道 B'：官方导入文件（最稳妥的路径）
bridge.write_series_import_txt(r"D:\q\out\series_100.txt", [("SSE.600519", 20240902, 1.0)])
```

CLI 一把梭：

```bash
python tdx_bridge.py --tdx-dir "C:/new_tdx" series     --csv signals.csv --series-id 100
python tdx_bridge.py --tdx-dir "C:/new_tdx" extern     --csv states.csv
python tdx_bridge.py --tdx-dir "C:/new_tdx" block      --block TQ_SIGNAL --symbols codes.txt
python tdx_bridge.py --tdx-dir "C:/new_tdx" series-txt --csv signals.csv --out series_100.txt
python tdx_bridge.py --tdx-dir "C:/new_tdx" selftest    # 临时目录里跑一遍读写自检
```

**CSV 列约定**：`series/series-txt` 用 `symbol,date,value`；`extern` 用 `symbol,text,value,data_id`；
首行表头可选；编码 UTF-8（读取时自动兼容 BOM）。

## 3. 落盘的四条硬约束（`tdx_bridge.py` 已内建）

| 约束 | 实现方式 | 为什么 |
|---|---|---|
| **幂等** | 序列数据整文件重写（按日期排序去重），不是追加 | 重跑一次不会把同一天写两遍；复用同一套日期口径 |
| **原子** | 先写同目录 `.tmp` 再 `os.replace` | 通达信不会读到写了一半的文件；被占用时重试并给出中文报错 |
| **编码** | 文本通道统一 GBK，遇到 emoji/生僻字**报错**而不是写坏 | 通达信按 ANSI 解析，UTF-8 会变乱码 |
| **可校验** | 每个 `write_*` 都有对应 `read_*`，写完立刻回读比对 | "写了"和"通达信能看到"是两件事 |

序列数据是**日期对齐**的：通达信按 K 线日期取数，停牌/缺 K 线的那天取不到值。
所以写"仓位状态"这类语义时，**必须逐日写满**（我们的示例就是把每个交易日都写上 0/1），
而不是只写"发生事件的那几天"。

## 4. 通达信端的一次性配置（人工做一次）

1. 打开通达信：`功能 → 公式系统 → 自定义数据管理器` → `新建`。
2. 建两个数据号，记下编号（示例：`100` = 仓位序列，`101` = 状态文字）。
   - 序列数据（日期+数值）与外部数据（字符串+数值）是两类，**都要建**。
3. 若要自动写二进制（通道 B），目录会自动出现：`T0002\signals\signals_user_100\`
   —— 第一次写入前建议先备份整个 `T0002\signals` 目录。
4. 板块通道 C：先在通达信里新建一个自定义板块（如 `TQ_SIGNAL`），让通达信在
   `T0002\blocknew\blocknew.cfg` 里登记好；之后 Python 只重写对应的 `.blk` 内容。
   **不要由脚本去改 `blocknew.cfg`**（那是登记表，格式敏感，改坏了板块列表会乱）。
5. 公式侧读取方式见阶段 5。

## 5. 本机验证清单（非官方机制，必须自证）

`.dat` 二进制布局与 `.blk` 市场号属社区实践，不同版本可能不同。首次接入按顺序做：

| # | 验证项 | 方法 | 通过标准 |
|---|--------|------|---------|
| 1 | 数据号已建好 | 自定义数据管理器里能看到 100/101 | 能看到 |
| 2 | 二进制布局正确 | 只写 3 条已知数据（如 20240902=1、20240903=2、20240904=3），在通达信里用 `SIGNALS_USER(100,0)` 画图 | 图上逐日显示 1/2/3 |
| 3 | 板块市场号正确 | 写 2 只沪市 + 2 只深市到 `.blk`，在通达信里打开该板块 | 4 只都对，无"多出来的怪票" |
| 4 | 北交所口径 | 写 1 只 8xxxxx 测试票 | 能显示 → 市场号 2 可用；不能 → 记录在本机说明里，改走通道 B' 导入 |
| 5 | 刷新行为 | 写入后不重启通达信，切换周期/重进视图 | 能看到新值（看不到就重启一次，并把"需要刷新"写进运维手册） |
| 6 | 读回一致 | `python example_strategy.py verify --tdx-dir ...` | 全部 `[OK]` |

## 6. 故障对照表

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 公式取到 0 或画不出线 | 数据号不匹配 / 该票该日期没有数据 | 核对数据号；确认写了**逐日**数据；用 `read_user_series` 读回 |
| 文字显示乱码 | 文件不是 GBK | 用 `tdx_bridge` 写入（它对非 GBK 字符直接报错）；不要把 UTF-8 文件扔进去 |
| 完全看不到新数据 | 通达信缓存未刷新 / 文件被占用导致未写成功 | 重进视图或重启；查看脚本退出码与日志；确认没有 OneDrive/杀软锁定 `T0002` |
| 板块里出现不存在的票 | `.blk` 市场号写错（深市写成 1） | 用 `read_block` 核对：返回的 (市场, 代码) 必须与预期一致 |
| 数据"看起来是旧的" | 脚本跑失败但静默通过 | 退出码必须非 0；`verify` 模式检查"最新日期距今天数"（> 7 天报警） |
| 写入报"文件被占用" | 通达信正在读该文件 | 关闭通达信后重试；或改在收盘后、软件空闲时写入 |
| 序列数据全空 | 写了空序列 / 日期格式不是 YYYYMMDD | `write_user_series` 会拒绝空输入；检查日期来源 |
