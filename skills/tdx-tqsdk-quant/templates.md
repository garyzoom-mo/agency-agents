## T4. 导出校验清单（阶段 4 质量门）

```bash
# 1) 幂等：连跑两次，文件字节必须一致
python example_strategy.py export --tdx-dir "C:/new_tdx"
sha256sum C:/new_tdx/T0002/signals/signals_user_100/*.dat > /tmp/run1.txt
python example_strategy.py export --tdx-dir "C:/new_tdx"
sha256sum C:/new_tdx/T0002/signals/signals_user_100/*.dat > /tmp/run2.txt
diff /tmp/run1.txt /tmp/run2.txt && echo "幂等 OK"

# 2) 读回校验
python example_strategy.py verify --tdx-dir "C:/new_tdx"

# 3) 异常路径（都要有明确中文报错且退出码非 0）
python tdx_bridge.py --tdx-dir "C:/new_tdx" series --csv bad_symbols.csv --series-id 100  # 期货代码
python tdx_bridge.py --tdx-dir "C:/不存在的目录" selftest                                 # 目录不对
```

| 检查项 | 期望 | 实际 |
|---|---|---|
| 幂等（两次字节一致） | 一致 | |
| 读回条数 = 写入条数 | 相等 | |
| 空序列被拒 | 报错 | |
| 期货代码被拒并给出替代方案 | 报错含"期货" | |
| emoji/非 GBK 字符被拒 | 报错含"GBK" | |
| 退出码：成功 0 / 参数错误 2 | 符合 | |

{=== 1. 副图：状态线 ===  类型：技术指标}

SIG:=SIGNALS_USER(100,0);

DRAWICON(READY AND SIG=1 AND REF(SIG,1)<1, LOW*0.98, 1);
DRAWICON(READY AND SIG<1 AND REF(SIG,1)=1, HIGH*1.02, 2);
DRAWTEXT_FIX(1, 0.01, 0.05, 0, STRCAT('信号：', EXTERNSTR(0,101))), COLOR00FFFF;

## T12. 运维手册模板（阶段 6 交付物）

```markdown
# 运维手册：{{策略名}}

## 每天怎么跑
1. 15:30 定时任务自动导出 → 2. 15:35 自动校验 → 3. 次日 09:10 人工确认

## 每天怎么看
- 通达信：打开 [主图公式] / [选股公式] / [板块]
- 日志：`logs/export_YYYYMMDD.log`，成功行形如 `[OK] SSE.600519: 121 条，最新 20260917=1`
- 审计：`state/audit_YYYYMMDD.json`

## 出问题怎么办（按顺序）
1. 放 `PAUSE` 文件 → 停止写入
2. 看 `verify` 输出与日志最后 50 行
3. 对照 04-signal-export 的故障对照表
4. 修完跑：selftest → demo → dry-run → export → verify
5. 复盘（T10）并写回 skill

## 本机已知限制（必须填）
- 刷新行为：写入后 [需要/不需要] 重进视图
- 北交所口径：[可用市场号2 / 不可用，改用 txt 导入]
- 通道可用性：[DLL 未使用 / 已绑定第 __ 号]
- 成本假设偏差：[实盘滑点观测值]

## 停机
- 暂停：放 `PAUSE`；彻底停：删除定时任务（命令见 06-live-ops）

## 联系人 / 凭据轮换周期
- 轮换周期：每季度；轮换后必须验证一次完整导出
```
